# 文档职责

每类持久事实只由一个文档负责。

| 文档 | 负责内容 | 不应包含 |
|---|---|---|
| `README.md` | 用途、安装、命令、运行方式、用户入口 | 架构理由和调查历史 |
| `DESIGN.md` | 项目级目标、非目标、整体行为、用户流程和验收边界 | 功能级规范 ID、包目录树和按时间排列的实现记录 |
| `spec/<feature>.md` | 功能级持久行为、稳定规范 ID、验收及就近追溯 | 项目级总览、任务时间线和全仓巨型矩阵 |
| `ARCHITECTURE.md` | 组件、边界、状态所有权、数据流、协议、不变量 | 产品待办和安装教程 |
| `LEARNING.md` | 可搜索、非显然、可复用的项目经验 | 例行变更和原始调试流水 |
| `docs/traces/YYYY-MM-DD.md` | 当天复杂任务按稳定编号追加的基线、重要调整、原因和最终变更映射 | 通用项目说明、工具流水和仅有最终结果的重复总结 |
| `docs/worklogs/YYYY-MM-DD.md` | 当天 Agent 任务按真实时间从旧到新排列的等级、结果、修改、验证和风险索引 | 当前产品/架构事实、完整差异和原始输出 |
| `docs/decisions/*.md` | 持久决策、备选方案及其后果 | 临时计划和实施日记 |

只创建确有必要的文档。优先完善已有权威来源，不增加相互竞争的文件。
