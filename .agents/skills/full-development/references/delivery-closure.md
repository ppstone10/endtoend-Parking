# 重大变更收尾

仅用于重大、关键或多范围变更。复用本轮已有证据，不把本文件变成第二轮开发流程。

1. 将最终结果逐项对应到用户要求和验收边界。
2. 将差异归为直接要求、必需协同修改或无关修改；移除本轮产生的无关内容，保留用户原有改动。
3. 将每个受影响范围映射到已运行验证；只对明确缺口补最小检查，不重复已被覆盖的命令。
4. 判断 README、DESIGN、ARCHITECTURE、LEARNING 和 TRACE 的实际影响，仅更新事实所属文档；已建立 TRACE 时追加最终变更映射，不覆盖旧检查点。
5. 检查本轮产生的调试日志、临时开关、占位内容和生成产物，安全清理任务自身产物。
6. 重大或关键变更确认迁移、回退、恢复、兼容性、安全和隐私风险。
7. 明确最终状态及剩余人工审查点。
8. 生成 Commit 文稿：建议标题、必要正文和不兼容变更说明。不得把未验证结果写成已通过，也不得自动提交或推送。
