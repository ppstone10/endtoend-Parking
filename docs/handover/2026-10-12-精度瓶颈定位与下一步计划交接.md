## 3. 根因（2026-10-12 探针后改写）

### 3.1 主因：误差沿预测时域自回归累积

同一批中途点上按轨迹相对位置分箱，误差均值 **0.197→0.251→0.275→0.359→0.490m** 单调上升，
P90 **0.319→1.008m**，而中位数保持平坦 0.14–0.19m。这是"上一步输出喂下一步"的复合误差特征。
**误差最大处正是终点段**，而任务对终点的要求最严（S4 离墙 0.3m、S8 台心 ±0.2m、S1/S2 位姿 ±0.3m）。

证据：[探针报告](../probe_representation_vs_precision.md) §4。

### 3.2 次因：确定性单点回归取的是示范的条件均值

在净空 < 0.2m 处（占中途点 2.9%）**误差 > 净空的比例达 97–100%**——均值在该处不可行。
远端未来本身有歧义，单点回归无法表达多模态。

### 3.3 ~~输入分辨率 / 特征层粗 / 解码看不见障碍~~ → **作为"精度下限的成因"已被否证**

以下三条**代码事实仍然成立**，但 2026-10-12 的两个探针否证了它们的**因果作用**：

| 事实 | 否证证据 |
|---|---|
| BEV 0.25m/格、特征 1 单元 = 2m、解码 320 步 `context` 固定 | 误差与局部净空**无关**（Spearman −0.012）；输入**粗化 4 倍**后 ADE/FDE **更好**（0.3002/0.4411 → 0.2772/0.2577） |

若精度由输入细节限制，粗化必须变差；实际没有。因此"提高分辨率 / 让解码器看局部几何"不成立。

**这改写了对旧现象的归因**：精度卡在 0.27–0.47m 的原因是**沿时域的复合**，不是局部看不见；
四种净空损失失败是因为它们约束局部净空、触及不到复合；几何过滤器只能把"撞"换成"停"
也同理；而专家零碰撞是因为 Hybrid A\* **不逐步展开**，没有复合误差。

对照：专家的误差是**有界且被验证**的（0.2m 外廓膨胀吸收离散化误差，平滑后再校验）；
网络的误差是**回归的统计产物**（自回归复合 + 多模态示范取平均）。

## 4. 已排除的方向（**勿重复投入**）

| 方向 | 结论 |
|---|---|
| 净空损失（四种形式：0.3 / 0.2 / 分层连续 / max 聚合） | 全部无效或有害（v18/v20/v27/v28） |
| 数据配比（DAgger 三轮、定向补采、全场景恢复） | 只能让能力在场景间**换位**，不提升总量（先导1/先导2/v38） |
| 标量损失权重、场景重加权 | 长期无提升 |
| 推理侧几何过滤作为能力 | 能把碰撞压到 30% 左右，但只是**把"撞"换成"停"**，不创造能力 |
| 单独加容量 | v37（h256 从头 30 epoch）失败：欠拟合 + 开环 ADE 0.4475 越过准入线 |

**规律：改变"被优化的对象"有效（v19 终点位姿损失 35.3%→58.8%）；在同一对象上加大力度无效。**

## 5. 待执行计划

### P0-A　门禁回退失败归零（**已于 2026-10-12 完成**）

- 结果：v34 协议 E5s 由 **78.3% / 0.0% / 回退失败 2** 变为 **89.0% / 0.0% / 回退失败 0**，三项判据全绿。
- 做法（规范 `SAFE-SHIELD-003`，见 `spec/safety_training.md`）：门禁由"回退不可用即终止回合"改为
  **三级退化阶梯**——主轨迹 → 可信回退 → **最小风险动作**（优先沿用上一条已验证安全参考的尾段，
  否则单点原地保持）；引擎侧在"替换参考通过审查但控制器实际推进仍不安全"时同样退到最小风险动作。
- 分场景：S3 36.5%→**80.8%**、S8 45.5%→**72.7%**、S6 61.4%→70.5%、S1 92.7%→96.4%；碰撞仍 0.0%。
- **性质**：不是"拖时间"换来的——时间/距离比 1.87→1.86、跟踪 RMS 不变、终点误差反而 1.00→0.59m。
- **同时推翻一条此前的根因结论**：原先认为门禁在 S3/S8 的上限受专家滚动重规划限制（E1r 30.8%/45.5%）。
  专家能力**完全未变**，门禁却把 S3 提到 80.8%、S8 提到 72.7% → 那两处的上限其实是**安全层过早放弃**。
- 剩余：`safety_stops` 仍有 16 条（原 49），为最后兜底路径；`expert_fallback_unavailable = 6`、
  `minimal_risk_holds = 0`（退化全部走了"沿用尾段"）。

### ~~P0-B　分辨率假设的否证实验~~ → **已否证并取消（2026-10-12）**

原计划：重建近场 12m @0.075m 数据集（1–2 天），判据"开环 ADE < 0.2m"。

**在做之前先跑了两个更便宜的探针，两者都否证了"输入分辨率是精度下限"这一假设**
（完整证据见 [探针报告](../probe_representation_vs_precision.md)）：

| 探针 | 结果 |
|---|---|
| 0a 误差–净空相关性 | **Spearman(净空, 误差) = −0.012**：误差与局部净空**无关**；净空从 0.2m 放宽到 1.0m，误差中位反而从 0.098m 升到 0.185m |
| 0b 输入粗化 4 倍 | 0.25m/格 ADE **0.3002** / FDE **0.4411**；**0.5m/格 ADE 0.2772 / FDE 0.2577**——去掉 75% 输入细节后**更好** |

→ 若精度受输入细节限制，粗化必须变差；实际没有。**"重建高分辨率数据集"不成立，取消**；
随之 P1-A 中"解码器每步读局部几何"的依据也被否证，一并取消。

**替换为 P0-C（见下）**：真正成形的机制是**误差沿预测时域自回归累积**——同一批点上按轨迹相对位置分箱，
误差均值 0.197→0.251→0.275→0.359→**0.490m**（单调 2.5 倍），P90 0.319→**1.008m**（3.2 倍），
而中位数保持平坦（0.14–0.19）——典型点仍准、远端出现重尾。**误差最大处正是终点段**，
而任务对终点的要求最严（S4 离墙 0.3m、S8 台心 ±0.2m）。

### P0-C　主攻复合误差（取代 P0-B/P1-A；数周级）

按预期收益排序，任一条都能直接削弱"逐步累积"：

1. **输出参数化**：320 步自由自回归的绝对点 → 相对位移/航向增量或低维机动参数（样条控制点）；
2. **非自回归/并行解码**：一次前向直接给出整条轨迹，复合误差在构造上不存在；
3. **消除 exposure bias**：teacher forcing 退火到 0（当前止于 0.2）、计划采样、或在自身滚动状态上训练；
4. **多模态/带不确定性输出**：远端未来本身有歧义，单点确定性回归取的条件均值常常不可行；
5. **缩短有效预测时域**：机动约 24s / 12m，而模型容量 320 点（64s）且损失对全部点等权——
   远端点既难学又与任务无关，却在主导损失。

判据：**开环 ADE 与"误差沿时域的斜率"同时改善**；只看总体 ADE 会被近端的好成绩掩盖。

### ~~P1-A　表征改造~~ → 见 P0-C（其"每步局部观测"一项依据已被否证）

### P1-B　关闭纯网络口径后的转向

**低于 5pt 的差异不作为改进**。

### P2-B　S3/S8 的专家滚动天花板专项

E1r 在 S3 只有 30.8%（**36/52 是超时、0 碰撞**）、S8 45.5%。这是**架构/场景问题**，与网络无关：

## 7. 口径与陷阱（会静默出错的地方）

1. **`_load_protocol` 的同源问题（已在代码中修，但要知道它发生过）**：输出目录与协议目录为**兄弟关系**时，
   会向上找到父目录的**旧**协议；把新协议索引套在旧数据上，样本因"无法复原"被静默丢弃——
   实测产出过"183 条 / 4 场景、S3/S5/S8 整段消失"却看起来完全合理的报告。
   现在 `--indices-file` 指向的协议优先，且运行开头会打印协议数据与索引条数，**每次都看一眼这两行**。
2. **选型在噪声上挑最高点**：相邻 checkpoint 的闭环选型得分在 **0%↔65%** 之间跳
   （v37：0/0/14/1/0；v38：25/4/65/39/25），说明策略对权重高度敏感。**模型间 5pt 以内的差异不算改进。**
3. **推理耗时是墙钟量**：并发负载下不可比（同架构的 v26 报 5.0ms、v38 报 11.6ms）。
   空载复测：h128 均 11.3ms、h256 14.8ms——**128 维基线本身也超过 NFR-05 的 10ms**，需单独查清口径。
4. **开环与闭环脱节**：v38 开环最差（ADE 0.4746 不达标）却闭环选型最好（65%/28%）。
   **开环指标不能作为闭环选型或准入依据**，且准入要求"先开环后闭环"——两个不达标的模型即由此被挡。
5. **`runs/` 与 `data/` 都在 `.gitignore`**：所有评测报告、checkpoint、恢复数据集都不入库，只留本地。
6. **test（S9，300 条）闭环从未执行**：开环已达标（ADE 0.216 / FDE 0.189），闭环按流程待 val 达标后**只跑一次**。

## 8. 需要决策的三件事

1. **是否继续保留"纯网络达标"这一宣称**——取决于 P0-B 的结果；若不成立，应正式关闭并改口径。
2. **门禁的降级语义如何定义**——"回退不可行"算降级行为还是失败，直接决定门禁三项判据是否全绿。
3. **论文交付形态**——"网络 + 运行时安全层"（现在就有证据链）还是坚持"纯网络"（需 P0-B/P1-A 成功）。
