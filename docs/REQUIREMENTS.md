# 需求基准（v2 · Python 仿真阶段）

> 本文档是后续实现的唯一需求基准，由 2026-08-23 评审与方案讨论确立，替代此前"最小闭环演示"阶段的隐含需求。
> 论文主题：基于端到端的无人矿卡自动泊车研究。
> 实验路线：Python 仿真（当前阶段，本文档范围）→ CARLA 仿真 → 履带小车实车。CARLA 与实车阶段仅替换传感器来源与底盘执行接口，网络输入输出契约保持不变。

## 1. 阶段完成标准（六维验收总纲）

Python 仿真阶段完成当且仅当以下六项全部达标：

| # | 标准 | 达标判据 |
|---|---|---|
| C1 | 接口定义好 | `interfaces/` 六类契约（传感器帧/BEV/状态/目标/轨迹/指令）稳定；模块单向依赖不变量成立；BEV 元数据（resolution/extent/channels）随数据持久化，无需调用方硬编码 |
| C2 | 轨迹输出有效 | 网络输出进入闭环并支撑泊车；有独立验证集；开环报告 ADE/FDE/航向误差；轨迹覆盖全程（非仅前若干米） |
| C3 | MPC 轨迹跟踪有效 | 专家轨迹+MPC 闭环成功率 ≥ 95%（统一批量协议下）；直线/曲线/倒车/扰动恢复单测通过；控制周期与轨迹 dt 对齐 |
| C4 | 效果可视化 | V1–V5 全套可视化（见 §8）自动产出，PDF+PNG 矢量双格式 |
| C5 | 效果可验证 | 论文 8 项指标 + 选位指标全部自动统计；批量实验配置驱动、可复现、结果落盘 |
| C6 | 模型可讲通 | 有对比基线与消融实验表格（含均值±标准差、多 seed）；数据集分层有统计描述；方法贡献点有实验支撑 |

## 2. 系统主线（不变）

```
LiDAR点云 / Camera图像
  → Sensor2BEV（5 通道融合 BEV）
  → MineParkingNet 端到端轨迹生成
  → 未来 N 个局部轨迹点
  → MPC 轨迹跟踪
  → [v_cmd, omega_cmd] → 平台执行器
```

坐标统一为车辆中心局部坐标系；网络不直接输出油门/转向。

## 3. 仿真场景库（真实矿场泊车场景覆盖）

场景来源为真实露天矿中六类泊车行为：驻地停车、维修车间、排土场卸载、破碎站卸料、装载对位、加油/称重停靠。精度值为行业典型值，用于各场景成功判定阈值。

| ID | 场景 | 泊车行为 | 关键几何 | 精度要求 |
|---|---|---|---|---|
| S1 | 驻地停车场 | 垂直入位（前进/倒车） | 2 排×N 车位（7×3.5m，车 6×3m），通道宽 9/12m 两档，划线车位，相邻随机占用 | pos±0.3m / yaw±10° |
| S2 | 斜列停车场 | 45° 斜位入位 | S1 变体，单向通道 | 同 S1 |
| S3 | 维修保养区 | 紧净空倒车入位 | 三面墙体+立柱+设备，单侧余量 0.5~0.8m | pos±0.3m / yaw±10° |
| S4 | 排土场卸载区 | 倒车贴挡墙停稳 | 卸载挡墙条带、挡墙外悬崖禁区（纯禁区、无点云）、3~5 卸载位、相邻等待卡车、可选拆线挡墙 | 尾部贴墙±0.3m / yaw±10° |
| S5 | 破碎站卸料口 | 倒车入窄槽居中 | 两侧混凝土墙间距 4.2m（单侧余量 0.6m）、入口挡柱、槽底料口禁区 | 居中±0.2m / yaw±5° |
| S6 | 装载工作面 | 前进对位 | 电铲多边形、台阶坡面、2~3 个不规则矿堆 | pos±0.5m / yaw±15° |
| S7 | 加油/加水站 | 平行停靠 | 中央加油岛、两侧平行位、后侧挡墙 | 与岛间距±0.3m / yaw±10° |
| S8 | 称重站 | 前进精准停线 | 导向墙+称重台标线 | 台心±0.2m |
| S9 | 综合矿场地图 | 跨区远距任务 | 100×60m：运矿道路（12m 宽、弯道、挡墙）串联 S1/S4/S5 区，路侧岩石 | 按目标区标准 |

场景实现要求：

- FR-SIM-01 多边形障碍：`PolygonObstacle`（凸多边形+圆），`ParkingEnvironment` 对外方法签名不变（is_free/has_collision/raycast），planner/传感器/BEV 零改动；`RectangleObstacle` 保留为其特例。
- FR-SIM-02 车辆参数化：`VehicleConfig`（默认矿卡 6×3m，4×2 保留作回归测试），规划器/MPC/碰撞检测统一读取。
- FR-SIM-03 噪声模型：LiDAR 距离高斯噪声+丢点+量程抖动；相机像素噪声+目标误检漏检；干净/低/高三档可配。
- FR-SIM-04 场景注册表：每场景参数化构造函数+元数据（类型/难度旋钮/精度标准/渲染样式），YAML 配置落盘可复现（seed/障碍/占用）。
- FR-SIM-05 场景自检：车位无碰撞、目标可达性抽验、图幅合法，注册时自动执行。
- FR-SIM-06 BEV 范围参数化：extent 随场景配置（默认 40×40m @0.25m），元数据持久化。

## 4. 任务变体（泊车情况覆盖）

任务 = 场景实例 + 起点位姿 + 目标（单个/候选集）+ 类型标签。难度轴正交叠加：距离档 × 机动方式（前进/倒车）× 相邻占用（0/1/2 侧）× 通道宽度 × 噪声等级。

| ID | 任务类型 | 定义 | 考察点 |
|---|---|---|---|
| T1 | 近距泊车 | 4~8m，通道内 | 单次机动精细对位 |
| T2 | 中距泊车 | 8~15m，含一次调头/绕行 | 多段机动组合 |
| T3 | 远距泊车 | 15~30m（S9 为主），沿道路行驶后泊入 | 滚动重感知、泛化 |
| T4 | 多车位选优 | 3~6 个空闲候选位自选并泊入 | 选择+泊车（见 §6） |
| T5 | 占用突变 | 泊车途中相邻车位被占/新增障碍 | 动态环境重规划（闭环引擎注入） |

- FR-TASK-01 任务采样器：按"场景(9)×任务类型(5)×难度轴"矩阵采样，每任务带全元数据，seed 可复现。

## 5. 数据与网络

### 5.1 专家系统与数据管线

- FR-PLAN-01 Hybrid A* 增强：Reeds-Shepp 解析扩展（近目标直接求值）；碰撞检测支持多边形。
- FR-PLAN-02 轨迹后处理：捷径平滑（shortcut+三次样条）+ 碰撞校验 + 梯形速度剖面（倒车段降速）。
- FR-DATA-01 分层数据集：按任务矩阵分层采样 3000+ 条；每条含 BEV/目标/状态/专家轨迹/任务元数据。
- FR-DATA-02 划分：train/val/test = 8:1:1；test 保留一类训练未见场景布局（泛化集）。
- FR-DATA-03 数据集体检：统计表（轨迹长度分布/倒车比例/场景占比）+ 抽样 BEV+专家轨迹叠加图。

### 5.2 网络（保留 v0 作 baseline）

- FR-NET-01 `net-v0`：现有 CNN+MLP 固定 horizon（baseline）。
- FR-NET-02 `net-v1`：变长输出（GRU/Transformer 自回归解码至终止符），覆盖任意长度轨迹。
- FR-NET-03 `net-v2`（主模型）：v1 + U-Net 跳连 BEV 编码 + goal/state 交叉注意力条件。
- FR-NET-04 模型注册表：`build_model(name, cfg)` 配置切换，不改代码。
- FR-NET-05 训练体系：YAML 配置驱动、checkpoint+early stopping（val loss）、训练曲线图、训练完成报告 ADE/FDE/航向误差。
- 退路：若变长解码训练不稳，固定 horizon=60+mask（覆盖 12m 全程），仍可完成全部实验。

### 5.3 对比与消融

- FR-BASE-01 基线组：Hybrid A*+MPC（经典上界）、直线插值+MPC、无 BEV（仅 goal+state）、纯 MPC 到目标点。
- FR-BASE-02 消融：BEV 通道（仅 occupancy/去 target/去 height/全通道）、条件（去 goal/去 state）、v0 vs v1、编码器深度/跳连。
- FR-BASE-03 全部实验 ≥3 seed，报告均值±标准差。

## 6. 多车位最优选取（方法贡献点）

- FR-SELECT-01 可解释评分器：对每候选位用专家规划器求轨迹，score = w1·路径长度 + w2·倒车里程 + w3·机动次数 + w4·最小净空风险 + w5·入位余量；输出分项表。评分器同时是 T4 的 oracle 标签生成器。
- FR-SELECT-02 主线路线 R1（分层式）：评分器选位 → 选定位姿作为 goal 条件 → MineParkingNet → MPC；接口契约不变。
- FR-SELECT-03 消融路线 R2（端到端式）：BEV target 通道渲染全部候选位，网络直接输出轨迹（隐式选择），评估选择一致性。
- FR-SELECT-04 指标：选位准确率（与 oracle 一致率）、选位代价差（归一化）；泊车成功率按自选位/指定最优位双口径统计。

## 7. 控制与闭环

- FR-CTRL-01 MPC 重做：数值梯度下降替换为 CEM 或 iLQR（纯 numpy）；控制周期与轨迹 dt 对齐；终态收敛判据含位置+航向双阈值；终点渐进减速。
- FR-CTRL-02 单测升级：直线/曲线/S 形倒车跟踪、外部扰动恢复（推离 0.5m 拉回）。
- FR-LOOP-01 滚动闭环引擎：每 K 控制周期重感知 → BEV → 网络推理 → MPC 跟踪；K 可调（K=1 为逐周期，亦为推理时间测量点）；终止条件：到达（按场景车位容差）/碰撞/超时/发散；失败自动分类（碰撞/超时/位姿超差/振荡）。
- FR-LOOP-02 动态注入：支持 T5 中途新增障碍。
- FR-LOOP-03 地基验收：专家轨迹+MPC 在 200 场景实例成功率 ≥ 95%（一切后续实验的前提）。

## 8. 指标与可视化

### 8.1 指标体系

- FR-METRIC-01 八项论文指标：泊车成功率（阈值随场景车位容差）、碰撞率、最终位置误差、最终航向误差、路径长度、泊车时间、MPC 跟踪误差（横向偏差 RMS）、网络推理时间（ms）。
- FR-METRIC-02 批量实验 runner：`--config` 驱动方法×场景集×噪声×seed 全组合，结果 JSON/CSV 落盘，断点续跑。
- FR-METRIC-03 主实验：8 场景×50 实例×5 方法×3 seed（约 6000 次闭环）。
- FR-METRIC-04 鲁棒性实验：噪声三级×丢点率递增×target 通道失效，成功率-噪声强度退化曲线。
- FR-METRIC-05 泛化实验：未见场景布局/未见车辆尺寸成功率。
- FR-METRIC-06 报告生成：均值±标准差表格（LaTeX/Markdown 双格式）+ 配对 t 检验。

### 8.2 可视化（matplotlib，PDF+PNG 矢量双格式）

- FR-VIZ-01 V1 场景地图：俯视图含车位（划线/编号/占用着色）、挡墙、悬崖斜纹、设备多边形、道路、起终点、图例、比例尺；S9 总览图。
- FR-VIZ-02 V2 泊车过程动画：世界俯视+车辆中心 BEV 双视图并排；规划轨迹点（序号虚线）、实际轨迹（实线+车身包络尾迹）、当前车辆矩形、目标框与容差圈、顶部读数（步数/v/ω/误差/碰撞状态）；输出 GIF+关键帧（起/调头/倒车/停稳）。
- FR-VIZ-03 V3 轨迹对比图：专家 vs 网络 vs 实际三线叠加 + 误差-时间双子图。
- FR-VIZ-04 V4 BEV 可视化：5 通道蒙太奇+融合伪彩+相机 IPM 中间结果。
- FR-VIZ-05 V5 实验汇总：按场景分组箱线图、选位准确率热图、成功率-噪声曲线。

## 9. 非功能需求

- NFR-01 可复现：场景/任务/实验全部 seed 化配置；同一配置两次运行结果一致。
- NFR-02 架构不变量：interfaces 契约、单向依赖（sim/sensor2bev/model/controller 只依赖 interfaces+numpy/torch）、车辆中心局部坐标系、差分驱动 [v,ω] 控制量。
- NFR-03 迁移就绪：三阶段仅替换传感器来源与底盘执行接口，网络契约不变。
- NFR-04 运行环境：conda 环境 `endtoend-parking`（Python 3.12），依赖 numpy/PyTorch(CPU)/matplotlib。
- NFR-05 性能：网络 CPU 推理单次 <10ms（必要时 BEV 分辨率降档作为消融项）；单次闭环 <10s。
