# 原生发出轨迹联合纠偏：一次有界修正与验收

## 元数据

- 规范前缀：EMIT-JOINT；强度：完整；状态：**联合目标已实现；LT34正式教师关口6/8严格通过，未过门槛，暂停拟合；联合目标收益未检验，关口2–4未执行**。
- 设计任务T-154605；实现任务T-161628，2026-10-28。执行边界见[LT34关口1/2计划](../docs/long_tasks/LT-20261028-34-emitted-joint-gates.md)。

## 目标

检验唯一主要假设：将位置/航向误差与原生停止选择联合约束，能否改善网络实际发出的轨迹，并转化为原生MPC闭环收益。成功应有同剂量对照下的可复现增量；失败应停止该配方，不自动追加轮数、扫描权重或改运行安全策略。

## 非目标

不重复旧冻结停止头、终点保持、单查询拟合或停止偏置搜索；不继续扩大LT33前缀规则。不证明网络容量不可能，不承诺一次损失修改能解决全部错误。不把专家/GT回退、教师长度、坐标/停止跨模型拼接、固定参考成功当作网络自主收益。

## 边界与约束

架构、输入per_view_v2、dt0.2、horizon320、原生stop0.5、原MPC、600步、每车位原tol_pos/tol_yaw与原安全审计保持。候选在显式实验副本训练，旧模型与配置不可覆盖，生产默认不变。

“原生”指sensor→network→mpc_vehicle、safety_mode=none，无专家替换或终端额外接管。接触与0.2m规划余量分别审计，安全停车不算到达。

训练只能来自现有训练域，严禁将LT32/LT33的val失败回灌。已反复使用的300例只作条件回归证据，不冒称独立未见测试。训练池留出仅表示不参与本轮更新，不能说父模型从未见过。

## 行为与验收

### EMIT-JOINT-001：先修正监督对象

实际验收长度必须由同一次自由解码输出的stop0.5首次交叉确定，无交叉使用完整horizon，与model.predict一致；实际末点是该长度最后一点。专家mask末点指标继续单列，不能替代原生发出指标。

候选新目标必须将停止选择与其对应位姿误差连接，至少对停止头和坐标头均存在有效训练信号。只按硬首停索引gather坐标、使停止头梯度为零的实现不满足本条；仅改变专家mask末点权重或补齐后缀也不满足。

本次只试一个代理：在**额外的自由解码**输出上，令 `h_t=sigmoid(logit_t/0.25)`，`q_t=h_t*Π_{j<t}(1-h_j)`（t<H），`q_H=Π_{j<H}(1-h_j)`，末步吸收没有首停的剩余概率。用log-sigmoid累计计算以避免极端logit溢出。`L_emit=mean_b Σ_t q_bt*(||xy_bt-goal_xy_b||²/tol_pos_b² + wrap(yaw_bt-goal_yaw_b)²/tol_yaw_b²)`。目标是输入中的原目标位姿，容差取各任务原值；不使用预测末点伪标签、不改变mask或停止BCE。

控制臂保持LT31 control原损失与teacher forcing0.2；干预臂只加 `0.1*L_emit`，温度/权重不扫描。自由分支保留坐标和停止梯度，不以teacher forcing输出代替实际发出对象；原分支仍按原配方训练。硬验收仅由未温度化的sigmoid>=0.5首停决定，无交叉取H，绝不使用q的均值/采样或教师长度截断。该代理是研究假设，可能偏爱过早停止或使坐标塌缩，原模仿约束和硬门槛负责暴露失败，不能把软损失下降当成功。

必须完成极端logit、无停止、角度环绕、原生长度一致性、两头梯度方向/有限性及默认关闭兼容测试，再冻结一次配方。不得为了凑齐计划放入未经实现的训练命令。

### EMIT-JOINT-002：教师与固定小集合前置门槛

在看新模型结果前，从训练源固定覆盖各场景/正倒车的小集合；建议8个任务，具体索引在代码准备时固定并登记，不按结果换成容易任务。训练/评估角色和来源SHA必须冻结。

本次小集合固定为LT29修复后train-balanced的索引 `[0,433,860,1290,1720,1975,2315,2]`：覆盖训练域实际存在的7个场景（无S7）及正倒车。每场景按元数据顺序取一例，S1额外补倒车；没有依据教师或网络结果挑样本。教师完整回合中的4个等间隔重规划输入（含起点、去重后最多4帧）构成沿程监督，按原全局固定标签的实际消费偏移取剩余有效前缀，其他位置仍置零。不新增专家求解、不调整标签、不用MPC消费稀疏mask冒充完整前缀；其可执行证据为同一教师回合实际连续执行，而非独立重置热启动后的新证明。

先核同输入监督的原联合终点、完整矩形参考余量及原MPC执行。如果教师都不能按原标准到达，停止该样本上的学习收益推断，先处理监督或控制契约，不能将责任归为网络学不好。不得通过替换失败教师样本隐去问题。

小集合拟合检查只回答该输入上的自主输出是否可学；若需要轨迹沿程输入，必须来自训练任务中有谱系、可执行的教师或恢复记录，不能用8个起点的记忆成绩声称覆盖滚动访问状态。

### EMIT-JOINT-003：一次配对修正，固定预算与停止条件

从同一LT31 control权重各自初始化、重置Adam；控制臂沿当前配方，干预臂只新增001目标。两臂同数据、顺序、seed、更新次数、学习率、teacher forcing及原损失，分别至少两个预先指定seed；不挑最佳seed或只报有利检查点。

更新预算、权重及检查时点在正式计划前一次固定。方案准备只做一次有界梯度/真实更新预检；不能拿小样本未改善无限追加训练。本次200次更新只是有限决策预算，不保证足够拟合，不能在失败后追认预算不足而自动加量。

代码固定一次预算：seed `20261028/20261029`，每臂各200次新Adam更新、lr1e-5/clip1、batch8（每任务每步一帧，帧在固定池内按seed采样），检查点0/50/100/200；最终只裁决200，不能挑较早检查点挽救失败。两臂同seed使用同一预生成样本序列及teacher forcing RNG。两seed新臂都须原生起点8/8及所有登记沿程帧末点/完整参考安全通过，才另行准备固定参考/滚动执行计划。正式教师关失败时禁止创建优化器或启动本阶段。

小集合门槛：自由解码的原生发出末点在全部8个固定输入上满足各自原位置/航向容差，完整原始参考安全；若不足8例、未核教师或只在teacher forcing/真值长度下过关，则不得扩大训练。该门槛只证明局部拟合，不证明滚动到达或泛化。

当前有限预算失败时，结论只能是“该实现/配方/预算未建立局部收益”；停止配方扩张，不据此断言架构学不会。若控制臂也失败，优先核优化、标签与表示；若控制臂通过而新臂失败，拒绝本次干预。

### EMIT-JOINT-004：将静态收益兑现为原生滚动收益

小集合通过后，先在同训练任务上分开检查固定首次预测与正常重规划原生闭环，不加oracle长度/专家替换。固定参考通过而重规划失败，转向访问状态覆盖/跨周期一致性；静态原生端点通过而固定参考也失败，转向动态可执行性。两种结果都不授权继续加大同一损失。

之后才允许独立的条件回归阶段，至少覆盖LT33全部22新回退+8恢复+5残余，以及当前原生93个成功，按并集唯一去重，不能只挑24例短检。val仅评估，不训练。

两seed分别与同剂量控制比较：原生成功至少增加1例，所有对照成功逐例保持，碰撞与余量侵入不增加，新增成功本身须无碰撞/无余量；任一seed出现旧成功回退或仅静态改善，拒绝扩大。该门槛是机制收益，不替代完整300、主线≥70%到达/≤10%碰撞与已有联合保持标准。GT混合成功不能替代原生收益，生产/五模块资格继续false。

### EMIT-JOINT-005：有限失败必须改变决定

| 观察结果 | 下一决定 |
|---|---|
| 教师/标签不能被原MPC按原标准执行 | 先修监督或控制契约，暂停训练收益试验 |
| 教师合格，但固定小集合仍不能自主发出合格轨迹 | 停止当前配方，核梯度/目标冲突/表示，不扩大数据或剂量 |
| 小集合可拟合，固定参考可执行，但滚动失败 | 转向真实访问状态覆盖与重规划一致性，不再称容量问题 |
| 小集合通过，固定参考执行失败 | 核网络参考动态可执行性与控制耦合，不把静态误差改善当修复 |
| 回归新增成功伴随旧成功丢失，或只有一个seed有效 | 拒绝候选，停止该配方扩张 |
| 两seed原生闭环有新增、无丢失、风险不增 | 才准备独立下一阶段完整验收，不自动启动 |

没有任何一步允许以“再探索一下”自动续跑相同配方。这个路线承诺形成明确决定，不承诺预先保证模型达标。
