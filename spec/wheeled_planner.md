# 轮式有界专家与安全转移 Spec

## 元数据

- Spec ID 前缀：`WHEEL-PLAN`
- 强度：完整
- 状态：已采纳
- 最后更新：2026-11-04

## 目标

- 将已有RS几何候选变成满足同一轮式离散运动约束、完整车体检查的专家参考。
- 允许合法移动机动修正终端朝向，不调用履带原地接管；无法生成则明确失败。

## 非目标

- 不宣称全局完备搜索、时间最优、全部矿区任务可解或碰撞形式保证。
- 本阶段无学习训练或正式300任务验收，旧规划器与履带基线不变。

## 边界与约束

- 在后轴参考点使用实际最小转弯半径生成RS候选，输出仍为车体中心。
- 每几何段起止停车，必要时停车调整转角；段内离散速度剖面从0加速再减至0，按原模型重放，不能直接拼接几何样本当执行标签。
- 所有控制变化、起终点和转移均按原配置审核；规划余量来自该配置。实际曲线与端点直线插值之间的最大弓高，加上扫掠器采样分辨率的一半，计入保守几何膨胀，再用已有矩形扫掠检查器检查；不是只检查中心点或四角。

## 行为与验收

### `WHEEL-PLAN-001`：带时序的合法专家

- 输入完整轮式状态和有限目标，先按模型刹停非零初速，再求后轴RS候选；显式dt、速度上限、候选数、输出步数及时间预算。
- 所有输出状态/控制逐步由同一model.step生成，最终速度为0、原目标位姿精度满足严格数值审核；返回绑定车型身份的WheeledTrajectory及独立可复核状态/指令。
- 段间换向经过零速，转角变化受限，停车转向时位姿不变；前进/倒车直线及需机动转向的目标均有短测。

### `WHEEL-PLAN-002`：完整车体及真实弧线转移检查

- 初始/终点碰撞直接拒绝；所有参考转移与实际执行转移都检查同配置规划余量。
- 起终点均自由但扫掠中间碰撞必须拒绝；对弧线中心轨迹采用弓高膨胀，超过pi的单步转角保守拒绝。
- 转移必须是前后状态在该dt下可复现的轮式动作，不能允许相同位置非零yaw转移混入。

### `WHEEL-PLAN-003`：有界失败及合法回退

- 时间/输出步数/候选预算受限；候选全部不合格则返回明确规划失败，不删除任务或替换目标。
- 回退可重新调用同一轮式专家；不能使用旧TerminalCaptureMPCController或在失败后以纯yaw控制完成任务。
- 可达/不可达只表述当前有限候选与预算下的结果，不能据此证明全局无解。

### `WHEEL-PLAN-004`：短闭环证据与身份

- 专家参考接第2环节MPC，实际转移独立审查，报告位姿到达、几何检查状态、失败及预测一致性；固定少量任务，非正式主表。
- 输入、参考和执行车型身份保持一致；未通过当前环节则不得生成正式训练集或扩大评测。

### `WHEEL-PLAN-005`：指定机动候选选择与失败解释

- plan可显式接收forward/reverse及有限的[0,1]最小里程占比（默认0.5）；省略请求时保留原首条合法候选行为。非法请求/阈值在发出控制前拒绝。
- 有请求时按完整真实模型状态（含必要刹停前缀）核算该方向里程占比。不合格候选应继续尝试原候选预算内的后续候选，不能把它当合格教师返回，也不能放宽目标/几何/步数/时间限制。
- 有限候选耗尽时保留候选首次失败计数（机动占比、几何、步数、终端等），而非仅以最后错误暗示唯一根因。时间预算单独标明，不能把未检查候选称已穷举。失败计数为候选层信息，不是每条路径全部潜在违规、任务互斥原因或全局不可解证明。

## 数据、接口与迁移

- 新规划器独立模块，复用原RS函数及矩形碰撞检查，原Hybrid A*/profile/终端控制不修改。
- 新参考携带完整状态和请求序列仅作专家审核证据，不在网络推理时泄漏未来控制或教师长度。
- 碰撞辅助依赖仿真完整几何，报告必须明确GT条件；无BEV安全或真实制动结论。
- 不迁移旧数据或修改旧SHA；停用新入口即可回退旧基线。没有硬件写入和外部服务。
